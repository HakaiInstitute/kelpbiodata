# Hakai Institute Nereocystis size fit

A fit of `kelpbio::kb_fit_size_nereo()` to maximum sub-bulb diameters
measured in July and August, the peak season, in Hakai Institute surveys
in British Columbia.

## Usage

``` r
fit_size_hakai_nereo
```

## Format

An object of class `c("kb_fit_size_nereo", "kb_fit_size", "kb_fit")`.
The data are in `fit$data`.
