# Hakai Institute Macrocystis wet/dry data

Wet and dry masses of Hakai Institute tissue samples in British
Columbia, all months and tissues pooled, one row per tissue sample.

## Usage

``` r
data_wetdry_hakai_macro
```

## Format

A tibble with 215 rows and columns:

- wet_mass_g:

  Wet mass of the sample (g).

- dry_mass_g:

  Dry mass of the sample (g).

## Source

Hakai Institute, *Macrocystis* kelp canopy productivity, version 1.4.0,
<https://doi.org/10.21966/k88j-1k50>.
