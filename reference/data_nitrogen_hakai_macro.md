# Hakai Institute Macrocystis nitrogen data

Sample and nitrogen masses of Hakai Institute tissue samples in British
Columbia, all months and tissues pooled, one row per dried tissue
sample.

## Usage

``` r
data_nitrogen_hakai_macro
```

## Format

A tibble with 191 rows and columns:

- sample_mass_mg:

  Mass of the dried sample analysed (mg).

- nitrogen_mass_ug:

  Nitrogen measured in the sample (µg).

## Source

Hakai Institute, unpublished tissue isotope data.
