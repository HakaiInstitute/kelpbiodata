# Hakai Institute Nereocystis nitrogen fit

A fit of `kelpbio::kb_fit_nitrogen_nereo()` to Hakai Institute tissue
samples in British Columbia, all months and tissues pooled, for
converting dry biomass to nitrogen without fitting a nitrogen model.

## Usage

``` r
fit_nitrogen_hakai_nereo
```

## Format

An object of class
`c("kb_fit_nitrogen_nereo", "kb_fit_nitrogen", "kb_fit")`. The data are
in `fit$data`.
