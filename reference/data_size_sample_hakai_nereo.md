# Hakai Institute Nereocystis size sample data

Maximum sub-bulb diameters measured in July and August, the peak season,
in Hakai Institute surveys in British Columbia, one row per plant.

## Usage

``` r
data_size_sample_hakai_nereo
```

## Format

A tibble with 2425 rows and columns:

- diameter_mm:

  Maximum sub-bulb diameter (mm).

- site:

  Site code, a factor (15 levels).

- year:

  Year, a factor (7 levels, 2019 to 2025).

## Source

Hakai Institute, *Nereocystis* kelp canopy productivity, version 1.3.0,
<https://doi.org/10.21966/d1s2-s530>.
