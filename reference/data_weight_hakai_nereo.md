# Hakai Institute Nereocystis weight data

Diameters and wet weights of plants harvested by the Hakai Institute in
British Columbia after day of year 140, measured at the maximum sub-bulb
diameter, one row per plant.

## Usage

``` r
data_weight_hakai_nereo
```

## Format

A tibble with 1184 rows and columns:

- diameter_mm:

  Maximum sub-bulb diameter (mm).

- weight_kg:

  Wet weight (kg).

- site:

  Site code, a factor (28 levels).

- year:

  Harvest year, a factor (7 levels, 2019 to 2025).

## Source

Hakai Institute, *Nereocystis* kelp canopy productivity, version 1.3.0,
<https://doi.org/10.21966/d1s2-s530>.
