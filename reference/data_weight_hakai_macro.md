# Hakai Institute Macrocystis weight data

Frond counts and wet weights of plants harvested by the Hakai Institute
in British Columbia, one row per plant.

## Usage

``` r
data_weight_hakai_macro
```

## Format

A tibble with 292 rows and columns:

- fronds:

  Fronds reaching 1 m above the holdfast, an integer.

- weight_kg:

  Wet weight (kg).

- site:

  Site code, a factor (20 levels).

- year:

  Harvest year, a factor (10 levels, 2016 to 2025).

## Source

Hakai Institute, *Macrocystis* kelp canopy productivity, version 1.4.0,
<https://doi.org/10.21966/k88j-1k50>.
