# Data attribution

The attribution statement for the data in kelpbiodata, to include in any
output that uses the reference datasets or fits.

## Usage

``` r
kelpbiodata_attribution()
```

## Value

A string.

## Examples

``` r
kelpbiodata_attribution()
#> [1] "The Hakai Institute data in this package were collected in collaboration with the Heiltsuk Integrated Resource Management Department (HIRMD) within Haíɫzaqv (Heiltsuk) territory. Any outputs using these data should credit both the Hakai Institute and HIRMD.
```
